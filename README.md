- 제작: Roblox Studio
### 발사
- **핫 런치 시스템:** 발사대에서 발사후  곧바로 점화해 가속하며 날아오릅니다.
- **4연장 발사대:** 발사할 때마다 발사대를 순서대로 바꿔 사용합니다.
- **발사 절차:** 무장 → 표적 선택 → 발사 순서이며, 쿨다운과 탄약, 재장전이 적용됩니다.
- **서버 판정:** 사거리 한계, 탄약, 쿨다운은 서버에서 최종 검증합니다

### 비행 단계 (3단계)
1. **부스트 단계:** 발사대 방향으로 가속하며 표적 쪽으로 서서히 조향합니다.
2. **피치오버 단계:** 표적 방향으로 선회하며, 표적이 위에 있는지 아래에 있는지에 따라 상승 또는 강하 경로를 선택합니다.
3. **종말 단계:** 표적에 충분히 가까워지면 정밀 호밍으로 전환합니다.

### 유도 방식
- **비례 항법 방식의 호밍:** 표적과 미사일의 상대 움직임을 보고 진행 방향을 보정합니다.
- **교전 모드 3종:** 탄도탄 방어, 순항미사일 방어, 항공기 방어 모드마다 선회 반응성과 유도 성격이 다릅니다.
- **선회 한계:** 미사일이 무한히 급회전하지 못하도록 한계를 두었습니다.
- **표적 위치 보정:** 먼 표적에서 발사 직후 움직임이 흔들리는 문제를 완화했습니다.
- **근접신관:** 표적에 일정 거리 안으로 들어오면 폭발합니다.
- **실패 처리:** 표적을 계속 놓치면 요격 실패로 판정하고, 일정 시간이 지나면 소멸합니다.

### 결과 처리
- 명중, 요격 실패, 오타격 세 가지로 구분해 교전 기록에 표시합니다.
- 발사 연기, 폭발 이펙트, 사운드, 카메라 흔들림으로 연출합니다.
